# 即時開票看板

給**總統大選**與**直轄市長、縣市長選舉**使用的票數統計與公開看板。
票數可以用四種方式進來（自動讀取、手機回報、CSV／Excel 匯入、後台輸入），
系統即時加總並推送到公開的看板頁面，觀眾不用重新整理就能看到最新數字。

> 本系統產生的是**非官方統計**，正式結果以中央選舉委員會公告為準；看板頁尾會固定顯示這句話。

## 功能

**公開看板**

- 總統大選：各組候選人得票、得票率、領先差距，各縣市領先地圖與得票表，可下鑽到鄉鎮市區、投開票所
- 縣市長選舉：各政黨領先縣市數、全國地圖、22 縣市各自的選情卡片，點進去看該縣市各鄉鎮市區
- 開票進度（已開出投開票所數）、投票率、有效票／無效票
- 即時更新（Server-Sent Events），斷線時自動改為輪詢；手機、平板、電腦皆可看，支援深色模式
- 「開票中」只標示**領先**，管理員把選舉設為「開票完成」後才標示**當選**

**轉播版面（電視開票風格）**

- 16:9 的播出畫面：候選人大頭照、以「萬」為單位的大字票數（例如 12 萬 2584）、得票率、直排地名
- 紅色／黃色快訊橫幅，管理員在後台打字就即時換上；沒有設定時自動顯示選舉名稱與開票進度
- 底部每幾秒輪播各縣市的前兩名，下方有時鐘與跑馬資訊，右側是各縣市領先地圖
- 個別候選人可以先蓋上「當選」章（自行宣布當選、或該選舉區已確定時使用）
- 可全螢幕投影、放電視牆，或在 OBS 等直播軟體加入「瀏覽器來源」（1920×1080）

**票數怎麼進來**

| 方式 | 說明 |
|---|---|
| 自動讀取 | 定時抓取 CSV 網址（例如發布到網路的 Google 試算表）或 JSON 網址；也可由外部程式用權杖推送 |
| 手機回報 | 回報員用手機登入，只能回報被指派的範圍；送出前要再核對一次數字 |
| CSV／Excel 匯入 | 下載已列好所有地區與候選人的範本，填好後上傳或直接貼上；先預覽、再確認 |
| 後台輸入 | 表格式逐列輸入，按 Enter 立即生效 |

**資料正確性**

- 每一筆回報／匯入／自動讀取都留下紀錄，永不覆寫；每個單位都能查歷次版本，另有操作稽核紀錄
- 回報員的票數預設要經管理員審核才生效（可改為直接生效；數字異常的仍會進審核）
- 自動驗證：非負整數、投票數不得超過選舉人數（警示）、表格若附「有效票」「投票數」會核對加總
- 管理員可以「鎖定」某個單位，自動來源與批次匯入就不會覆蓋它
- 重複匯入同一份資料是安全的，數字沒變不會產生新紀錄

## 快速開始

需要 [Node.js](https://nodejs.org/) 22.18 以上。

```bash
npm install
```

```bash
npm run build
```

```bash
npm start
```

打開 <http://localhost:3000>。第一次啟動時，終端機會顯示管理員帳號與一組隨機密碼（只顯示一次），
請到 <http://localhost:3000/admin> 登入後立刻到「我的密碼」更改。
也可以先把 `.env.example` 複製成 `.env`，自行設定 `ADMIN_PASSWORD`。

### 先看看實際的樣子

從中選會選舉資料庫匯入真實的歷屆結果（2024 總統大選、2022 縣市長選舉），需要能連上 `db.cec.gov.tw`：

```bash
npm run demo
```

模擬開票：伺服器啟動後，在另一個終端機執行下面的指令，它會把 2024 總統大選的票數分批送進系統，
約兩分鐘「開完」，可以看到看板即時跳動。這也適合當作開票日前的演練。

```bash
npm run demo -- --simulate
```

## 開票日的建議流程

1. **建立選舉**（後台 › 選舉列表）。選擇類型與「票數登錄到哪一層」：
   - 縣市：每個縣市一筆，最省人力
   - 鄉鎮市區：368 筆，看板可以下鑽到鄉鎮
   - 投開票所：最細，需要先匯入投開票所清冊（可分批匯入；還沒匯入的鄉鎮暫時以整個鄉鎮為一筆）
2. **設定候選人**（逐一新增，或用表格批次匯入）。顏色依政黨自動配色，可以修改。
3. **決定票數來源**：設定自動讀取的網址，或建立回報員帳號並指派範圍，或準備匯入用的表格。
4. **演練**：選舉在「草稿」狀態下只有管理員看得到，回報與匯入都能照常操作。演練完到「總覽與設定」按「清除全部票數」。
5. 開票開始時把狀態改為**開票中**，看板就會公開並即時更新。
6. 全部開完、核對無誤後改為**開票完成**，領先者會改標「當選」，回報也隨之關閉。

## 轉播版面怎麼用

1. 後台 › 選舉 › **候選人**：在每位候選人那一列上傳照片（系統會自動裁成直式大頭照）。沒有照片時會顯示剪影。
2. 後台 › 選舉 › **轉播版面**：
   - 按「開啟轉播版面」，在新分頁按右上角「全螢幕」。網址是 `/e/選舉編號/tv`，觀眾不需要登入。
   - **快訊橫幅**：輸入文字、選紅底或黃底，按「更新快訊」，所有開著的畫面會立刻換上。
   - **大版面的選舉區**（縣市長選舉）：可指定左右各放哪個縣市，例如固定放臺北市、新北市；沒指定的位置會自動輪播。
   - **公開連結預設開啟**：選「轉播版面」的話，一般的看板連結會直接進入轉播版面（網址加 `?detail=1` 可看詳細看板）。
3. 某位候選人自行宣布當選、或該選舉區結果已確定時，到「候選人」頁按**標示當選**，看板會立刻蓋上當選章。
   這是人工判斷，系統不會自動蓋章；整場選舉設為「開票完成」後，各選舉區的最高票會自動顯示當選。

畫面固定以 1920×1080 設計並等比例縮放，任何螢幕上的構圖都相同。各候選人顯示的是該選舉區得票最高的兩位；
還沒有票數時，優先顯示主要政黨的候選人。

## 表格格式

到後台「匯入／匯出」下載範本最省事。自己準備表格的話：

- 第一列是欄位名稱，順序不拘
- **地區**：用 `代碼` 一欄，或 `縣市` ＋ `鄉鎮市區`（＋ `投開票所` 編號）。「台」與「臺」通用
- **候選人得票**：欄名用號次（`1號`、`2號`…）或候選人姓名。縣市長選舉各縣市共用一張表時請用號次
- 選填欄位：`無效票`、`選舉人數`、`投開票所總數`、`已開出投開票所數`
- 若有 `有效票` 或 `投票數` 欄，系統會核對加總，不符的列會被擋下
- 整列票數空白代表尚未開出，會自動略過
- 檔案可以是 CSV（UTF-8 或 Big5）、Excel `.xlsx`，或直接從 Excel 複製貼上

```csv
縣市,鄉鎮市區,1號,2號,3號,無效票,選舉人數
臺北市,松山區,26090,41183,50049,744,157451
```

自動讀取的 JSON 網址與 API 推送使用這個格式（`votes` 的鍵是候選人號次）：

```json
{ "results": [
  { "code": "63000010", "votes": { "1": 26090, "2": 41183, "3": 50049 },
    "invalid": 744, "eligible": 157451, "stationsTotal": 120, "stationsCounted": 85 }
] }
```

### 關於開票進度與投票率

- 以投開票所為單位登錄時，進度就是已回報的投開票所數。
- 以縣市／鄉鎮市區為單位時，請一併提供「投開票所總數」與「已開出投開票所數」，看板才知道開到哪裡；
  沒提供的話只會顯示「已回報幾個區」。
- 投票率只計入**確定開完**的地區（避免開到一半時算出偏低的數字）；選舉設為「開票完成」後會計入全部。

### 關於中選會的資料

- 內建的「中選會選舉資料庫」來源讀取的是 `db.cec.gov.tw` 上**選後公布的正式結果**，
  可用來匯入歷屆選舉，或在選後把看板更新為官方數字。
- 開票當晚的官方即時計票資料需事先向中選會申請，格式每屆公告，本系統沒有內建。
  拿到資料後，把它轉成上面的 JSON 格式，用「JSON 網址」或「API 推送」接進來即可。

## 部署

所有資料都在單一檔案 `data/vote.db`（SQLite），備份這個檔案就是備份整個系統。

用 Docker：

```bash
docker build -t vote-dashboard .
```

```bash
docker run -d -p 3000:3000 -v vote-data:/data -e ADMIN_PASSWORD='請換成你的密碼' -e COOKIE_SECURE=1 -e TRUST_PROXY=1 vote-dashboard
```

環境變數見 `.env.example`。正式對外服務時請注意：

- 一定要放在 HTTPS 後面，並設定 `COOKIE_SECURE=1`、`TRUST_PROXY=1`
- 反向代理要保留原本的 `Host` 標頭；`/api/stream` 是長連線，需關閉緩衝（Nginx：`proxy_buffering off;`）
- 開票當晚流量大時，建議前面再放一層 CDN 或快取代理
- 伺服器要能連到你設定的自動讀取網址

```bash
npm run dev
```

會同時啟動 API（:3000，改檔自動重啟）與前端開發伺服器（:5173，請開這個）。

| 路徑 | 內容 |
|---|---|
| `server/domain.ts` | 選舉、選舉區、候選人、統計單位 |
| `server/results.ts` | 票數登錄與審核、各層級加總（所有來源都走 `submitResult`） |
| `server/importer.ts` | CSV／Excel／JSON 轉換與批次套用、範本與匯出 |
| `server/sources.ts` | 自動讀取排程、中選會選舉資料庫轉接 |
| `server/app.ts`、`server/admin.ts` | 公開、回報、後台 API |
| `web/src/App.tsx`、`web/src/components/` | 公開看板、地圖、圖表元件 |
| `web/src/pages/TvPage.tsx`、`tv.css` | 轉播版面 |
| `web/src/pages/ReportPage.tsx` | 手機回報 |
| `web/src/admin/` | 管理後台 |
| `scripts/build-geo.mjs` | 重新產生行政區清單與地圖（行政區調整時才需要） |

伺服器以 Node.js 內建的 TypeScript 支援直接執行，不需要另外編譯；資料庫使用 Node.js 內建的 SQLite。
